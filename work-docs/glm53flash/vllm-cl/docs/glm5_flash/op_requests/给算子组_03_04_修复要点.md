## 一、[Operator Request][P0] `dlc_kda_chunk_prefill`：每次调用必抛异常、launch 出的 kernel 卡死设备、`beta_logits` 被就地改写

### 问题摘要

`torch.dlc_kda_chunk_prefill` 目前 **100% 调用失败**（与输入数据无关，任何 shape 都必现），
且失败时设备已被 launch 出去的 kernel 弄坏；另外 kernel 会把调用方的 `beta_logits` 输入就地改写成 sigmoid 结果。

GLM-5.3-Flash 的 KDA chunked prefill 需要它，因此本算子当前**完全不可用**，插件只能继续走逐 token 递推。

### 实测现象

1. 调用必抛异常（异常在 kernel 已经 launch 之后才抛）：

```
RuntimeError: /root/workspace/pytorch/aten/src/ATen/native/TensorShape.cpp:1417(_permute_size_stride_estimation)
permute(sparse_coo): number of dimensions in the tensor input does not match the length of the desired
ordering of dimensions i.e. input.dim() = 5 is not equal to len(dims) = 4
```

2. 抛出异常后，**该设备再做最普通的算子也会永久挂住**（实测：`a + 1.0` + `torch.dlc.synchronize()` 超时；
本次复现把 `dlc:5` 打到必须复位），说明 launch 出去的 kernel 本身没有正常结束。

3. `beta_logits` 被就地改写（代码审阅确认，见下）。

### 根因与修复建议

1. **返回值 5 维用 4 阶 permute（必现异常，一行修复）** —— `aten/src/ATen/native/dlc/FusedOps.cpp:845`：

```cpp
auto q_dlc   = q.permute({3, 2, 1, 0}).unsqueeze(-1);          // [D, H, N, 1, 1]
auto out_dlc = at::empty_like(v_dlc);                            // 也是 5 维
auto final_state_dlc = at::empty_like(initial_state_dlc);        // 也是 5 维
kernel.launch("custom_dlc_kda_chunk_prefill");
return std::make_tuple(out_dlc.permute({3, 2, 1, 0}), final_state_dlc.permute({3, 2, 1, 0}));
//                                  ^^^^^^^^^^^^^^^ 5 维张量只给了 4 个维度 → RuntimeError
```

   建议改成 `out_dlc.squeeze(-1).permute({3, 2, 1, 0})`、`final_state_dlc.squeeze(-1).permute({3, 2, 1, 0})`，
   期望返回 `out=[1,N,H,Dv]` bf16、`final_state=[B,H,Dv,Dk]` fp32。

2. **kernel 自身必须能正常结束（否则修好 permute 也还是不可用）**：异常是在 `kernel.launch()` 之后抛的，
   所以调用方即使 `try/except` 也会赔上一张卡。请检查 `custom_dlc_kda_chunk_prefill`
   在 `H=8, Dk=Dv=128, T=64, chunk=64` 这个最小用例下是否越界/死循环。
   另外建议：**所有输入校验放到 `kernel.launch()` 之前**，避免「校验失败但 kernel 已经跑出去」。

3. **`beta_logits` 被就地改写** —— `DLC_Custom_Kernel/dlc_kernels/attention/kda/dlc_kda_chunk_prefill.cpp:416-418`：

```cpp
HBM2VMem(beta_hbm, vmem_beta, N * ALIGN128(H));
sigmoid_bf16(vmem_beta, vmem_beta, N, H);
Vmem2HBM(vmem_beta, beta_hbm, N * ALIGN128(H));   // beta_hbm = 调用方 beta_logits 的地址
```

   公开 schema（`aten/src/ATen/native/native_functions.yaml:465`）里 `beta_logits` 没有 `Tensor(a!)` 标注，
   上层会当它只读；实际被写回后，调用方的张量被静默污染（多步复用 / CUDA graph 下是隐性错数）。
   建议：要么写内部缓冲，要么把 schema 标成 `Tensor(a!)` 并在文档里写明。

4. **请在修复时一并定死两处语义冲突**：
   - `beta` 语义：kernel 内部对 `beta_logits` 做了 sigmoid（即期望传**原始 logit**）；
     而插件 `vllm_cl/patch/patch_kda.py:550-552` 的 chunk 路径传的是**已经 sigmoid 过的 fp32** beta
     （上游注释：「chunk path wants the pre-sigmoided fp32 beta (its kernels don't sigmoid)」），
     且本算子要求 bf16。这三点（内部 sigmoid / 预 sigmoid / dtype）必须与插件对齐，否则接入就是错的；
   - `g_bias` 布局：本算子公开签名是 `[D, H]`（wrapper 内 `permute({1,0})`），
     而同批的 `dlc_kda_recurrent_decode` 要 `[H, Dv]` —— **两个算子相反**，极易接错，建议统一。

### 验收标准

1. `probe_new_kda_chunk_prefill.py dlc:N --wedge-device` 能**正常返回**：
   `out=[1,N,H,128]` bf16、`final_state=[B,H,128,128]` fp32，且 `probe_device_health.py dlc:N` 仍然 `OK`（设备没坏）；
2. 数值与段末的 fp32 逐 token 递推参考一致（`out_err` bf16 量级、`final_state` 相对误差 ≤1e-3），
   覆盖 `T=64/200/变长 [64,130,7]`、`chunk_size=64/128`、`B=1/3`；
3. 调用后**调用方传入的 `beta_logits` 不被修改**（脚本里已保存副本，可直接断言）；
4. `g_bias` 与 `beta` 的语义/布局在 issue 里写明并与 `dlc_kda_recurrent_decode` 对齐。

```python
"""#03 新算子 dlc_kda_chunk_prefill 复现脚本（2026-09-22，2026-09-22 晚改为两段式）。

GLM5 几何：H=8(TP8), Dk=Dv=128；q/k/v/raw_g [1,T,H,128] bf16，beta_logits [1,T,H] bf16，
a_log [H] fp32，g_bias [D,H] fp32（wrapper 内 permute 成 [H,D]），initial_state [B,H,Dv,Dk] fp32，
query_start_loc [B+1] int32，lower_bound=-5.0，query_scale=128**-0.5，chunk_size=64。

两段式用法（**默认不碰设备**）：
  A) 静态复现（无需 DLC 设备，证明 host wrapper 必抛异常）：
       python probe_new_kda_chunk_prefill.py --static
  B) 真机复现（**会把设备卡死，必须在可复位的卡上跑**）：
       python probe_new_kda_chunk_prefill.py dlc:5 --wedge-device

背景：host wrapper 在 `kernel.launch()` 之后才对 5 维张量做 4 阶 `permute`，所以调用方
**即使捕获了异常，设备也已经被 launch 出去的 kernel 弄坏**（实测必须复位才能再用）。
"""
import sys
import time
import torch

WEDGE = "--wedge-device" in sys.argv
args = [a for a in sys.argv[1:] if not a.startswith("--")]
dev = args[0] if args else "dlc:0"
torch.manual_seed(0)
H, D = 8, 128
LB, SCALE = -5.0, 128 ** -0.5


def static_repro():
    print("=== A) 静态复现（不开 DLC 设备）===", flush=True)
    print("FusedOps.cpp:780-845 的真实调用序列（简化）：", flush=True)
    v = torch.zeros(1, 7, H, D)                       # [1,N,H,D]
    v_dlc = v.permute({3, 2, 1, 0}).unsqueeze(-1) if False else v.permute(3, 2, 1, 0).unsqueeze(-1)
    print(f"    v               : {tuple(v.shape)}", flush=True)
    print(f"    v_dlc           : {tuple(v_dlc.shape)}  ← .permute({{3,2,1,0}}).unsqueeze(-1) 后已是 5 维", flush=True)
    out_dlc = torch.empty_like(v_dlc)
    print(f"    out_dlc         : {tuple(out_dlc.shape)}  ← at::empty_like(v_dlc)，同样 5 维", flush=True)
    try:
        out_dlc.permute(3, 2, 1, 0)
    except Exception as e:
        print(f"    out_dlc.permute({{3,2,1,0}}) -> {type(e).__name__}: {str(e)[:200]}", flush=True)
    print("    → 与真机报错同一条（host wrapper 返回处 5 维张量用 4 阶 permute，必现、与输入数据无关）", flush=True)


def make(lens, chunk):
    """a["beta_logits"] / a["initial_state"] 是调用方张量的副本，用于确认是否被就地改写"""
    B, N = len(lens), sum(lens)
    q = (torch.randn(1, N, H, D, dtype=torch.bfloat16, device=dev) * 0.5).contiguous()
    k = (torch.randn(1, N, H, D, dtype=torch.bfloat16, device=dev) * 0.5).contiguous()
    v = (torch.randn(1, N, H, D, dtype=torch.bfloat16, device=dev) * 0.5).contiguous()
    raw_g = (torch.randn(1, N, H, D, dtype=torch.bfloat16, device=dev) * 0.5).contiguous()
    beta = (torch.randn(1, N, H, dtype=torch.bfloat16, device=dev) * 0.5).contiguous()
    a_log = (torch.randn(H, dtype=torch.float32, device=dev) * 0.5).contiguous()
    g_bias = (torch.randn(D, H, dtype=torch.float32, device=dev) * 0.2).contiguous()
    st0 = torch.randn(B, H, D, D, dtype=torch.float32, device=dev) * 0.05
    qsl = torch.tensor([0] + torch.cumsum(torch.tensor(lens), 0).tolist(),
                       dtype=torch.int32, device=dev)
    return dict(q=q, k=k, v=v, raw_g=raw_g, beta_logits=beta, a_log=a_log,
                g_bias=g_bias, initial_state=st0, query_start_loc=qsl), st0.clone(), beta.clone()


def case(name, lens, chunk=64):
    a, st0, beta0 = make(lens, chunk)
    t = time.time()
    try:
        out, fin = torch.dlc_kda_chunk_prefill(
            a["q"], a["k"], a["v"], a["raw_g"], a["beta_logits"], a["a_log"], a["g_bias"],
            a["initial_state"], a["query_start_loc"], float(LB), float(SCALE), int(chunk))
        torch.dlc.synchronize()
        print(f"[{name}] 成功 out={tuple(out.shape)} fin={tuple(fin.shape)} t={(time.time()-t)*1e3:.2f}ms",
              flush=True)
    except Exception as e:
        print(f"[{name}] lens={lens} chunk={chunk} -> {type(e).__name__}: {str(e)[:170]}", flush=True)
        print("    异常抛出时 kernel.launch() 已发生 → 该设备已被卡死：**不要再读回任何 DLC 张量",
              flush=True)
        print("    （任何 .item()/synchronize() 都会永久挂住）**，请直接换卡；本脚本到这里即退出。",
              flush=True)
        print("    `beta_logits` 被就地改写见 kernel `dlc_kda_chunk_prefill.cpp:416-418`"
              "（sigmoid_bf16 后 Vmem2HBM 写回调用方地址），已由代码审阅确认。", flush=True)
        sys.exit(3)


print(f"dev={dev} wedge_mode={WEDGE} H={H} D={D}", flush=True)
static_repro()
if not WEDGE:
    print("=== B) 真机复现已跳过（默认安全模式）===", flush=True)
    print("    要复现「必抛异常 + 卡死设备 + beta_logits 被就地改写」，请在**可复位**的卡上执行：", flush=True)
    print("    python probe_new_kda_chunk_prefill.py dlc:5 --wedge-device", flush=True)
    sys.exit(0)

print(f"=== B) 真机复现（会卡死设备）dev={dev} ===", flush=True)
case("b1-64", [64])
case("b1-200", [200])
case("b3-var", [64, 130, 7])
case("b1-200-c128", [200], chunk=128)
case("b1-4", [4])
```

```python
"""设备体检：确认某张 DLC 卡是否还能跑最普通的算子（卡死后必须复位）。
```

## 二、[Operator Request][P0] `dlc_kda_recurrent_decode`：`out` 逐位恒为 0（单行修复）

### 问题摘要

`torch.dlc_kda_recurrent_decode` 的 **state 递推数值完全正确**（与 fla 语义逐项对齐 `state_err≈3e-5`，bf16 量级），
但 **`out` 逐位恒为 bf16 的 0**（`(out == 0).all() == True`、`out.abs().max() == 0.0`），无论是否显式传 `out=` 都一样；
预填 7.0 再调用会被覆写成 0（说明写操作发生了，写进去的值是 0）。因此该算子目前不能用。

### 实测现象（H=8, Dk=Dv=128, 输入为正常随机量）

| 用例 | state | out |
|---|---|---|
| `lens=[1]` / `[2]` / `[4]` / `[1,1,1,1]` / `[3,1,2]` | `state_err = 2.6e-05 ~ 4.4e-05`（|ref|≈0.25） | `out_err=1.3e-02`，而 `|ref_out|max=0.0131` → **out 全 0** |
| `out` 预填 7.0 | — | 被覆写成 0（`(out==0).all()==True`） |
| `num_accepted_tokens=[2]`（T=4） | 与「整窗提交」`3.0e-05`；与「第 2 token 快照」`2.6e-01` → **accepted 未生效** | 全 0 |

### 根因与修复建议（一行）

`DLC_Custom_Kernel/dlc_kernels/attention/kda/dlc_kda_recurrent_decode.cpp:189`：

```cpp
v_f32_st_tnsr_st_msk(0, raw_vmem, 1, 1, __$F(float_to_bfloat16(v_u32_move_f(0.0f), output)));
//                                                                        ^^^^^ 常量 0.0f 被放进 torch 回读的那半
```

紧邻的 state 写回是正确的（所以 state 一直对）：

```cpp
state_row += broadcast_lane(k, key) * delta;
v_f32_st_tnsr_st_msk(0, row, 1, 1, state_row);
```

修复方向：把真正的 `output` 放到 torch 回读的那半（两个实参互换，或两半都放 `output`），
与 q/k/v 读取侧的 bf16 约定保持一致即可；**不需要改数学**。

### 另外两项请在修复时一并处理

1. **state 布局：请统一为 `[S,H,Dv,Dk]`（2026-09-22 已确认）**：交付版声明的是 `recurrent_state=[S,H,Dk,Dv]`
   （行 = key 维），与插件 `_run_kda` / fla 的 `[pages,H,V,K]`（行 = value 维）互为转置。实测两者**语义完全一致、
   只是存储转置**（两组不依赖参考实现的判决用例：`state=0,k=e5,v=e3,β=1` → 只有 `[dk=5, dv=3]=sigmoid(1)`；
   `state=1,只剩衰减` → 沿 dim2 变化、dim3 不变且逐值等于 `exp(-5·sigmoid(g_bias))`）。
   因为 Dk=Dv=128，接错**不会报错、只会静默把 key/value 轴用反**。**算子组已同意统一为 `[S,H,Dv,Dk]`**
   （#03 的 `initial_state`/`final_state` 同步改为 `[B,H,Dv,Dk]`），插件侧零转换。
   新布局的 fp32 参考实现：`refs/kda_reference_dv_dk.py`（`recurrent_decode_ref` / `chunk_prefill_ref`，
   自带 `--selftest`：chunk 版与逐 token 递推在 `lens=[1]/[2]/[4]/[7]/[16]/[1,1,1,1]/[5,2,1,3]`、
   `chunk=1/2/8/64` 下误差 <1e-7）。
2. **`num_accepted_tokens` 未生效**：形参被接受（schema/校验都在），但 state 总是按整窗 T 提交，
   没有按 accepted 截断（即 spec 回滚语义缺失）。插件现在不支持 spec（`fused_recurrent_kda_dlc` 直接
   `NotImplementedError`），但既然签名声明支持，请实现它（或从签名删掉，避免误用）。

### 其他接口约束（接入要用，供确认）

- `lower_bound` 必须**精确等于 -5.0**（硬校验）；`A_log` 要 1D `[H]` fp32；`g_bias` 要 `[H,128]` fp32；
- 所有输入必须 contiguous 且 `storage_offset==0`；物理行必须是 512 B（`dlc_dim0_padded_*dlc_layout_==512`）；
- `state_indices` 支持 `[B]` 或 `[B,next_n]`；`num_accepted_tokens` 为 `[B]`；`v` 的 `Dv ≤ 128`；
- `out` 必须与 `v` 同形、contiguous，且不能与 `recurrent_state` 互为别名。

### 验收标准

1. `probe_new_kda_recurrent_decode_fla_ref.py dlc:N` 输出中 `out 逐位为 0 = False`，且 `out_err` 与 `|ref_out|max` 同量级降到 bf16 精度（相对误差 ≲1e-3）；
2. `state_err` 保持在本轮水平（`≈1e-5 ~ 1e-4`），五组 lens 全部通过；
3. 传 `num_accepted_tokens=[2]`（T=4）时，state 与「第 2 个 token 后快照」吻合（而不是整窗）；
4. 修复后与插件 native 做一次端到端对齐（布局统一为 `[S,H,Dv,Dk]` 后**不需要任何转换**）。
5. 用 `refs/kda_reference_dv_dk.py --compare-device dlc:N` 对拍（该脚本用 `--selftest` 在 CPU 上先自检；
   **#03 要加 `--force-chunk`，未修复前会卡死设备**，请在可复位的卡上跑）。

### 附：复现脚本全文（`probes/probe_new_kda_recurrent_decode_fla_ref.py`）

```python
"""#04 新算子 dlc_kda_recurrent_decode 复核（2026-09-22 晚，替代初版 ..._layout.py）。

初版 `probe_new_kda_recurrent_decode_layout.py` 的参考实现把衰减轴写错（把 per-Dk 的 gate 施加到 Dv 上），
得出了「T=1 时 state 不吻合」的错误结论，已废弃删除；本脚本是修正版，用于给算子组复现/验收：

判据（全部与 fla / 上游 KDA 语义一致）：
  h = [S_slot, H, Dk, Dv]（dim2 = key 维），衰减 exp(g) 沿 Dk，proj[dv] = Σ_dk h[dk,dv]·k̂[dk]，
  h += k ⊗ (β·(v - proj))，o[dv] = Σ_dk h[dk,dv]·(q̂[dk]·scale)。
已知缺陷：`out` 逐位恒为 0（kernel `dlc_kda_recurrent_decode.cpp:189` 把常量 0.0f 写进 torch 回读的那半）。
用法：`python probe_new_kda_recurrent_decode_fla_ref.py <dev:dlc:N>`
"""
import sys
import torch

dev = sys.argv[1] if len(sys.argv) > 1 else "dlc:0"
torch.manual_seed(1)
H, DK, DV = 8, 128, 128
LB, SCALE = -5.0, 128 ** -0.5


def ref_fla(state, lens, q, k, v, raw_g, beta, a_log, g_bias, acc=None, commit="full"):
    """h=[S,H,Dk,Dv]；commit='full' 整窗提交，'accepted' 在第 acc 个 token 后快照"""
    N = q.shape[1]
    st = state.clone()
    o = torch.empty(1, N, H, DV, dtype=torch.float32, device=dev)
    qsl = [0]
    for l in lens:
        qsl.append(qsl[-1] + l)
    for b in range(len(lens)):
        s, e = qsl[b], qsl[b + 1]
        h = st[b + 1].float().clone()
        for t in range(s, e):
            qt, kt, vt = q[0, t].float(), k[0, t].float(), v[0, t].float()
            qt = qt * torch.rsqrt(qt.square().sum(-1, keepdim=True) + 1e-6)
            kt = kt * torch.rsqrt(kt.square().sum(-1, keepdim=True) + 1e-6)
            gate = LB * torch.sigmoid(torch.exp(a_log)[:, None] * (raw_g[0, t].float() + g_bias))
            h = h * torch.exp(gate).unsqueeze(-1)                   # per-Dk（dim2）
            bt = torch.sigmoid(beta[0, t].float())
            delta = (vt - (h * kt.unsqueeze(-1)).sum(-2)) * bt.unsqueeze(-1)
            h = h + kt.unsqueeze(-1) * delta.unsqueeze(-2)
            o[0, t] = (h * (qt * SCALE).unsqueeze(-1)).sum(-2)
            if commit == "accepted" and acc is not None and t - s + 1 == acc[b]:
                st[b + 1] = h.clone()
        if commit == "full":
            st[b + 1] = h
    return st, o


def call(states, lens, q, k, v, raw_g, beta, a_log, g_bias, acc=None, out_init=None):
    B, N = len(lens), sum(lens)
    sidx = torch.tensor(list(range(1, B + 1)), dtype=torch.int32, device=dev)
    qsl = torch.tensor([0] + list(torch.cumsum(torch.tensor(lens), 0)), dtype=torch.int32, device=dev)
    acc_t = None if acc is None else torch.tensor(acc, dtype=torch.int32, device=dev)
    st = states.clone()
    out = torch.full((1, N, H, DV), 7.0 if out_init is None else out_init,
                     dtype=torch.bfloat16, device=dev)
    torch.dlc_kda_recurrent_decode(q, k, v, raw_g, beta, a_log, g_bias, st, sidx, qsl, acc_t,
                                   lower_bound=LB, scale=SCALE, out=out)
    torch.dlc.synchronize()
    return st, out


def rand_case(lens, seed=1):
    torch.manual_seed(seed)
    B, N = len(lens), sum(lens)
    g = lambda *s: (torch.randn(*s, dtype=torch.bfloat16, device=dev) * 0.5).contiguous()
    return dict(lens=lens,
                q=g(1, N, H, DK), k=g(1, N, H, DK), v=g(1, N, H, DV), raw_g=g(1, N, H, DK),
                beta=g(1, N, H),
                a_log=(torch.randn(H, dtype=torch.float32, device=dev) * 0.5).contiguous(),
                g_bias=(torch.randn(H, DK, dtype=torch.float32, device=dev) * 0.2).contiguous(),
                base=torch.randn(B + 1, H, DK, DV, dtype=torch.float32, device=dev) * 0.05)


def numeric_cases():
    print("=== A) 数值对齐（fp32 fla 语义参考）===", flush=True)
    for lens in ([1], [2], [4], [1, 1, 1, 1], [3, 1, 2]):
        c = rand_case(lens)
        r_st, r_out = ref_fla(c["base"], lens, c["q"], c["k"], c["v"], c["raw_g"], c["beta"],
                              c["a_log"], c["g_bias"])
        st, out = call(c["base"], lens, c["q"], c["k"], c["v"], c["raw_g"], c["beta"],
                       c["a_log"], c["g_bias"])
        s_err = (st[1:].float() - r_st[1:]).abs().max().item()
        o_err = (out.float() - r_out).abs().max().item()
        print(f"    lens={str(lens):18s} state_err={s_err:.3e}（|ref|={r_st[1:].abs().max().item():.3f}）"
              f"  out_err={o_err:.3e}（|ref|={r_out.abs().max().item():.4f}）"
              f"  out 逐位为 0 = {bool((out == 0).all())}", flush=True)


def accepted_cases():
    print("=== B) num_accepted_tokens 语义（T=4, acc=2）===", flush=True)
    c = rand_case([4])
    st, _ = call(c["base"], [4], c["q"], c["k"], c["v"], c["raw_g"], c["beta"], c["a_log"],
                 c["g_bias"], acc=[2])
    for commit in ("full", "accepted"):
        r_st, _ = ref_fla(c["base"], [4], c["q"], c["k"], c["v"], c["raw_g"], c["beta"],
                          c["a_log"], c["g_bias"], acc=[2], commit=commit)
        err = (st[1:].float() - r_st[1:]).abs().max().item()
        print(f"    与「{commit:8s}提交」比：state_err={err:.3e}", flush=True)
    print("    → 阈值判断：哪个 err 小，就是算子当前的提交语义", flush=True)


def layout_cases():
    print("=== C) 受控判决（不依赖参考实现）===", flush=True)
    z_b = lambda *s: torch.zeros(*s, dtype=torch.bfloat16, device=dev)
    z_f = lambda *s: torch.zeros(*s, dtype=torch.float32, device=dev)
    k = z_b(1, 1, H, DK); k[0, 0, :, 5] = 1.0
    v = z_b(1, 1, H, DV); v[0, 0, :, 3] = 1.0
    beta = torch.ones(1, 1, H, dtype=torch.bfloat16, device=dev)
    st, out = call(z_f(2, H, DK, DV), [1], z_b(1, 1, H, DK), k, v, z_b(1, 1, H, DK), beta,
                   z_f(H), z_f(H, DK))
    nz = (st[1, 0].abs() > 1e-3).nonzero()
    print(f"    C1 state=0,k=e5,v=e3,β=1 → 非零元 {nz[:2].tolist()}（期望 [5,3]），值={st[1,0,5,3].item():.4f}"
          f"（期望 sigmoid(1)=0.7311）", flush=True)
    g_bias = (torch.arange(DK, dtype=torch.float32, device=dev)[None, :].repeat(H, 1) * 0.05).contiguous()
    ones = torch.ones(2, H, DK, DV, dtype=torch.float32, device=dev)
    kb = z_b(1, 1, H, DK); kb[0, 0] = 1.0
    st, _ = call(ones, [1], z_b(1, 1, H, DK), kb, z_b(1, 1, H, DV), z_b(1, 1, H, DK),
                 torch.full((1, 1, H), -20.0, dtype=torch.bfloat16, device=dev), z_f(H), g_bias)
    m = st[1, 0]
    exp_g = torch.exp(-5 * torch.sigmoid(g_bias[0]))
    print(f"    C2 state=1,只剩衰减 → 沿 dim0(Dk) 方差={m.var(dim=0).mean().item():.3e}"
          f"  沿 dim1(Dv) 方差={m.var(dim=1).mean().item():.3e}（期望：dim0 非零、dim1 为 0）", flush=True)
    print(f"    C2 m[:5,0]（沿 Dk）={[round(x,6) for x in m[:5,0].tolist()]}", flush=True)
    print(f"    C2 exp(-5σ(g_bias))[:5]={[round(x,6) for x in exp_g[:5].tolist()]}（应与上行逐值吻合）", flush=True)


print(f"dev={dev} H={H} Dk={DK} Dv={DV}", flush=True)
numeric_cases()
accepted_cases()
layout_cases()
print("=== D) 结论 ===", flush=True)
print("    state：数值正确（bf16 级），布局 [S,H,Dk,Dv]（行=Dk），衰减沿 Dk —— 与插件 native 语义一致、存储互为转置；", flush=True)
print("    out：逐位恒为 0（P0 缺陷，见 issue 正文的 kernel 行号）；num_accepted_tokens：未生效，总是提交整窗。", flush=True)
```
